# AI-Generated Practice Questions

The questions in this directory (`cloud-concepts.json`, `security.json`, `infra-compute-storage.json`,
`data-network-ai.json`, `billing-support.json`) were **generated by A.I** (Claude, by Anthropic) from the
tasks and domains published in the official AWS Certified Cloud Practitioner (CLF-C02) exam guide:

https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html

Published exam-prep books were read only as a map of topics and common traps. No question text was copied
from them. Every fact (service behavior, limits, plan names, pricing models, scope) was then checked against
the AWS documentation linked at the end of each lesson. Pricing figures and plan details change, so confirm
them on the AWS pages before relying on them for a purchase decision. The questions are **original practice
material**. They are not AWS questions, they do not come from AWS Skill Builder or from any exam, and they do
not represent actual exam questions.

For AWS's own official practice question set, sign in to AWS Skill Builder from the certification page:

https://aws.amazon.com/certification/certified-cloud-practitioner/
