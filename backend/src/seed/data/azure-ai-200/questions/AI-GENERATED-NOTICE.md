# AI-Generated Practice Questions

The questions in this directory (`containers.json`, `data.json`, `services.json`,
`security-monitoring.json`) were **generated by A.I** (Claude, by Anthropic) from the skills
measured published in the official Microsoft study guide for Exam AI-200:

https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-200

Facts such as limits, defaults and API behavior were checked against the Microsoft Learn
documentation linked at the end of each lesson. The questions are **original practice material**.
They are not Microsoft's questions, they do not come from the Microsoft Practice Assessment or
from any exam, and they do not represent actual exam questions.

For Microsoft's own practice assessment, sign in to AI Skills Navigator from the certification page:

https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-cloud-developer-associate/
