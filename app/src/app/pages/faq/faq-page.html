Frequently asked questions

Show your books on your profile

The Library tab of a public profile lists the books you write in a file of the project's repository. You add the file with a pull request, and the profile reads it from there.

  1. Keep your profile public (it is by default) and sign in with the GitHub account that will name the file.
  2. Fork the project repository on GitHub.
  3. In your fork, create this file, using your GitHub login in lowercase: public/books/your-login.md
  4. Fill it with one block of lines per book, like the example below.
  5. Open a pull request. A check confirms that the author of the pull request owns the file.
  6. After the merge, your books show up on your Library tab within about 15 minutes.

The rules

  • title, url and pages are required. cover and comment are optional.
  • Put each book between two --- lines, like the metadata at the top of a concept. A blank line also ends a book.
  • pages is the total number of pages, from 1 to 5000. It sets how thick the book is on the shelf.
  • cover is the address of the cover image. Without it the book shows its title on a plain cover.
  • comment is plain text shown with the title when the book is opened. Each comment line is a paragraph, up to 4 lines of 500 characters. Links and formatting are shown as typed, never interpreted.
  • url and cover must start with https://. A book that breaks a rule is ignored; the other books still show.
  • Up to 200 books per file.

Prefer a table?

A table works too, one row per book: the title as a link, the pages and the cover (it can be empty). It has no comment column, and a title cannot contain the | character. You can mix tables and blocks in the same file.
