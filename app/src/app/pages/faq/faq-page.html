Show your books on your profile

The Library tab of a public profile lists the books you write in a file of the project's repository. You add the file with a pull request, and the profile reads it from there.

  1. Keep your profile public (it is by default) and sign in with the GitHub account that will name the file.
  2. Fork the project repository on GitHub.
  3. In your fork, create this file, using your GitHub login in lowercase: public/books/your-login.md
  4. Fill it with a table like the one below, one row per book.
  5. Open a pull request. A check confirms that the author of the pull request owns the file.
  6. After the merge, your books show up on your Library tab within about 15 minutes.

The rules

  • First column: the title as a link to the book, written [Title](https://link).
  • Second column: the total number of pages, from 1 to 5000. It sets how thick the book is on the shelf.
  • Third column: the address of the cover image. It can be left empty.
  • Links and covers must start with https://. A row that breaks a rule is ignored; the other rows still show.
  • Up to 200 books per file, and no | character inside a title.

The file is public and carries your GitHub login, so anyone can tie the books on your profile to your GitHub account.
